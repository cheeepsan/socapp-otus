# What to install

1. Install JDK 11
2. Install sbt https://www.scala-sbt.org/
3. Install docker + docker-compose

# How to run

1. `docker compose up -d`
2. `sbt run`

Curl example:
```

curl -s -X POST http://localhost:8080/user/register \
  -H "Content-Type: application/json" \
  -d '{"first_name":"Ivan","second_name":"Petrov","birthdate":"1990-01-15","city":"Moscow","password":"secret-1"}'

```
